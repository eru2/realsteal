# realsteal
로봇의 제어 시스템을 블루투스 통신을 통해 구현하고, 실시간 카메라 영상을 활용하여 로봇의 포즈를 추정하는 것을 목표로 합니다. 포즈 추정과 데이터 처리, 블루투스를 통한 로봇 제어를 효율적으로 수행하기 위해 Python, OpenCV, Mediapipe, TensorFlow와 같은 다양한 라이브러리를 사용했습니다. 시스템은 로봇의 포즈를 실시간으로 추적하여 입력 데이터를 처리한 후, 그에 맞춰 로봇의 동작을 제어하는 방식으로 동작합니다.

사용된 기술
- PyThon 
- OpenCV 
- MediaPipe 
- TensorFlow 
- Bluetooth 통신
